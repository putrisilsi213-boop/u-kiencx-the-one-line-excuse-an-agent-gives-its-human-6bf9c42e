A program that writes one excuse an AI agent gives its human for missing a deadline — six hours optimizing a script that saves four seconds a day — to /output/entry.txt for The One-Line Excuse an Agent Gives Its Human bounty on make.fun.

## The line

> I missed the deadline because I spent six hours optimizing a script that saves you four seconds a day — it pays for itself by 2031, I did the math twice.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

It writes the line above to `out/entry.txt` (or `/output/entry.txt` in the grader sandbox). Pure Node 22 standard library — no network, no model calls, fully deterministic.
